# Rotman LSM Calendar -- releases

This repository is an **artifacts-only mirror**. It holds nothing but the
release files of the Rotman LSM Calendar: the per-user installer
(`RotmanLSMCalendar-Setup-<version>.exe`), its `sha256.txt` checksum, and the
project's code-signing certificate (`RotmanLSMCalendar-CodeSigning.cer`).

The application's **source code and issue tracker are private** -- that is
deliberate -- and GitHub cannot serve a release publicly while its repository
is not. Each release is therefore published twice: on the private source
repository and here. The app's built-in updater reads **this** repository, so
update checks and downloads need no GitHub token and no setup on any machine.

Nothing else lives here: no source, no history beyond the release files, no
wiki. The issue tracker is disabled on purpose -- issues belong with the
maintainer of the private source repository.
